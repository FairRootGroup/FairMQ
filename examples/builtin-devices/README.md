# Example builtin-devices: a topology of built-in devices

The built-in devices fairmq-bsampler, fairmq-splitter, fairmq-proxy, fairmq-merger, fairmq-multiplier and fairmq-sink in one topology, without own code.

The documentation explains the code, the topology and the commands:
